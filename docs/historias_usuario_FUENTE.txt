                +LISTA DE HISTORIAS DE USUARIO – KUYAYPET
                                       Proyecto de Ingeniería de Software

Las siguientes historias de usuario se han elaborado a partir de las funciones definidas para KuyayPet:
búsqueda y visualización de mascotas en adopción, filtros y compatibilidad, cercanía geográfica, Like/Dislike,
Match, chat y contacto entre adoptantes y responsables.

Usuarios principales del sistema
  • Adoptante: Persona interesada en encontrar y adoptar una mascota.
  • Responsable de mascota: Persona que publica o gestiona una mascota disponible para adopción.
  • Usuario común: Persona que utiliza la plataforma y sus funciones de búsqueda, interacción y contacto.
  • Administrador de la plataforma: Usuario con privilegios de administrador

1.​ Enunciado
     Como          usuario común
     Quiero        registrarme en KuyayPet
      Para         poder acceder a la plataforma



2.​ Criterios de aceptación
-​    DADO que el usuario se encuentra en la pantalla de registro, CUANDO desea crear una cuenta, ENTONCES el
      sistema debe solicitar nombre, correo electrónico y contraseña.
-​    DADO que el usuario se encuentra completando el formulario de registro, CUANDO intenta registrarse dejando uno o
      más campos vacíos, ENTONCES el sistema debe indicar que todos los campos son obligatorios.
-​    DADO que el usuario se encuentra completando el formulario de registro, CUANDO ingresa su correo electrónico,
      ENTONCES el sistema debe validar que tenga un formato válido.
-​    DADO que el usuario se encuentra completando el formulario de registro, CUANDO ingresa una contraseña,
      ENTONCES el sistema debe validar que tenga como mínimo 8 caracteres.
-​    DADO que ya existe una cuenta asociada al correo ingresado, CUANDO el usuario intenta registrarse con ese mismo
      correo, ENTONCES el sistema no debe permitir crear una nueva cuenta.
-​    DADO que el usuario ha completado correctamente todos los datos requeridos, CUANDO selecciona la opción de
      registrarse, ENTONCES el sistema debe crear la cuenta y mostrar un mensaje de confirmación.
-​    DADO que el usuario está completando el formulario de registro, CUANDO ingresa algún dato inválido, ENTONCES el
      sistema debe mostrar un mensaje indicando el error.

      mostrar un mensaje informativo.

       HU-04 – FILTRAR MASCOTAS SEGÚN PREFERENCIAS
1.​ Enunciado:
          Como          Adoptante
          Quiero        Filtrar las mascotas según mis preferencias
           Para         Encontrar opciones que se ajusten mejor a lo que busco

2. Criterios de aceptación
-​   DADO que el sistema muestra las mascotas disponibles, CUANDO el adoptante selecciona la opción
     “Filtros”, ENTONCES el sistema debe mostrar las opciones de filtrado disponibles.
-​   DADO que el adoptante se encuentra en la sección de filtros, CUANDO selecciona una o más
     preferencias, ENTONCES el sistema debe permitir seleccionar dichos criterios antes de aplicarlos.
-​   DADO que el adoptante ha seleccionado un filtro, CUANDO selecciona la opción “Aplicar filtros”,
     ENTONCES el sistema debe actualizar la lista de mascotas mostrando únicamente aquellas que
     cumplen con el criterio seleccionado.
-​   DADO que el adoptante selecciona varios filtros, CUANDO los aplica, ENTONCES el sistema debe
     mostrar las mascotas que cumplan con los criterios seleccionados.
-​   DADO que existen mascotas que cumplen con los filtros seleccionados, CUANDO se muestran los
     resultados, ENTONCES el sistema debe permitir al adoptante visualizar las mascotas encontradas.
-​   DADO que no existen mascotas que coincidan con los filtros seleccionados, CUANDO el adoptante
     aplica los filtros, ENTONCES el sistema debe informar que no se encontraron mascotas que cumplan
     con los criterios.
-​   DADO que el adoptante ha aplicado filtros, CUANDO modifica alguno de los criterios, ENTONCES el
     sistema debe actualizar los resultados de acuerdo con las nuevas preferencias.
-​   DADO que el adoptante ha aplicado uno o más filtros, CUANDO selecciona la opción “Limpiar filtros”,
     ENTONCES el sistema debe eliminar los criterios seleccionados y mostrar nuevamente las mascotas
     disponibles.
-​   DADO que el adoptante ha aplicado filtros, CUANDO selecciona una mascota de los resultados,
     ENTONCES el sistema debe permitirle acceder al perfil de dicha mascota.
-​   DADO que el adoptante ingresa nuevamente a la sección de mascotas después de haber limpiado
     los filtros, CUANDO visualiza la lista, ENTONCES el sistema debe mostrar las mascotas disponibles
     sin restricciones de filtrado.

-​    DADO que no existen mascotas disponibles dentro del radio seleccionado, CUANDO el adoptante realiza la búsqueda,
      ENTONCES el sistema debe mostrar un mensaje indicando que no se encontraron mascotas cercanas.

             HU-07 – RECIBIR UN MATCH POR COMPATIBILIDAD
    1.​ Enunciado:

              Como          Adoptante
              Quiero        Recibir un Match cuando exista interés compatible
               Para         Saber que puedo continuar con el proceso de contacto.



    2.​ Criterios de aceptación
    -​   El sistema debe permitir identificar cuando existe un interés compatible entre el adoptante y una
         mascota.
    -​   Dado que el adoptante ha indicado que está interesado en una mascota, cuando el responsable
         también manifieste interés en continuar con el proceso, entonces el sistema debe generar un Match.
    -​   Dado que existe un Match entre el adoptante y una mascota, cuando se genere la coincidencia,
         entonces el sistema debe notificar al adoptante que se ha producido un Match.
    -​   Dado que el adoptante recibe una notificación de Match, cuando acceda a la sección de
         coincidencias, entonces debe poder visualizar la mascota con la que obtuvo el Match.
    -​   El sistema debe mostrar información básica de la mascota asociada al Match.
    -​   Dado que el adoptante tiene un Match activo, cuando seleccione la coincidencia, entonces el sistema
         debe permitirle continuar con el proceso de contacto con el responsable.
    -​   El Match debe quedar registrado en la cuenta del adoptante para que pueda consultarlo
         posteriormente.
    -​   Dado que no existe interés compatible, cuando el adoptante revise sus posibles coincidencias,
         entonces el sistema no debe generar un Match.

HU-08 – COMUNICARSE CON EL RESPONSABLE DE LA MASCOTA
 1.​ Enunciado:

           Como         Adoptante
           Quiero       Comunicarme mediante un chat con el responsable de una mascota
            Para        Solicitar información y coordinar una posible adopción.



 2.​ Criterios de aceptación
 -​   El sistema debe permitir al adoptante iniciar una conversación con el responsable de una mascota.
 -​   Dado que el adoptante ha seleccionado una mascota en adopción, cuando presione la opción de
      iniciar chat, entonces el sistema debe abrir una conversación con el responsable de dicha mascota.
 -​   Dado que existe una conversación entre el adoptante y el responsable, cuando el adoptante envíe un
      mensaje, entonces el sistema debe registrar y mostrar el mensaje dentro del chat.
 -​   Dado que el responsable ha enviado un mensaje, cuando el adoptante ingrese a la conversación,
      entonces debe poder visualizar el mensaje recibido.
 -​   Dado que el adoptante se encuentra dentro del chat, cuando consulte la conversación, entonces el
      sistema debe identificar la mascota relacionada con dicha conversación.
 -​   El sistema debe mostrar los mensajes enviados y recibidos en orden cronológico.
 -​   Dado que el adoptante necesita información adicional sobre la mascota, cuando envíe una consulta
      mediante el chat, entonces el responsable debe poder recibirla y responderla.
 -​   El adoptante debe poder consultar posteriormente el historial de la conversación para continuar la
      coordinación de la posible adopción.
 -​   Dado que la adopción ya no continuará, cuando la conversación sea finalizada, entonces el sistema
      debe conservar el historial de mensajes para su consulta posterior.
